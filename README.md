**📖 Descripción**

Este repositorio contiene los laboratorios, actividades dirigidas, ejercicios prácticos y proyectos desarrollados durante el curso de Minería de Datos correspondiente al semestre 2026-I.
A lo largo del curso se aplicaron técnicas de análisis de datos, aprendizaje supervisado y evaluación de modelos predictivos utilizando Python y Google Colab.

**📂 Contenido del Repositorio**

LAB S05	Evaluación de Modelos y Métricas

LAB S06	k-NN y Regresión Logística – Heart Disease

LAB S08	Árboles de Decisión – Employee Attrition

**📈 Competencias Desarrolladas**
- Durante el desarrollo de este portafolio se aplicaron:
- Limpieza y preparación de datos.
- Análisis exploratorio de datos (EDA).
- Ingeniería de características.
- Entrenamiento de modelos de clasificación.
- Evaluación mediante Accuracy, Precision, Recall, F1-Score y AUC.
- Validación Holdout y K-Fold Cross Validation.
- Interpretación de resultados para la toma de decisiones.

**⭐ Proyectos Destacados**
- Predicción de Churn

- Loan Default Prediction
- Predicción de incumplimiento crediticio mediante algoritmos supervisados.
- Employee Attrition
- Análisis de rotación de empleados utilizando árboles de decisión.
- Detección de Fraude
- Aplicación de Redes Neuronales Artificiales para la identificación de transacciones fraudulentas.

**🎯 Objetivo del Portafolio**
Evidenciar el aprendizaje adquirido durante el curso de Minería de Datos mediante la aplicación práctica de técnicas analíticas y modelos predictivos en diferentes casos de negocio.
